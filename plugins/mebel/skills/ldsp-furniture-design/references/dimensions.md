### 1.5 Угловые модули
- Нижний угловой "L" (90 град): 900x900 (по столешнице), дверь 300+300 / складная; реже 1000x1000.
- Нижний прямой угловой с "глухой" зоной: 1000-1200 по фронту (дверь 400-600 + заглушка/фальшпанель ~100-150 для прохода ручек и фасадов).
- Верхний угловой "L": 600x600 (глубина 300), дверь ~300-320; трапеция 600x600.
- Между угловым модулем и соседним фасадом — вставка (зазорник) 50-100, чтобы ручки/фасады не бились.

### 1.6 Рабочий треугольник и проходы
- Сторона треугольника 1200-2700 (оптимум 1500-2000), сумма 4000-7000 (практика 4500-6500).
- Мойка-плита 600-900 (min 500); плита-холодильник 400-600 (min 300); рядом с плитой рабочая зона >= 300-400 с каждой стороны; от плиты до края столешницы/стены >= 200-300.
- Проход между рядами 1000-1200 min (1200-1500 оптимум; два человека 1500).
- Зазор до стены при планировке 20-30.

### 1.7 Расчёт фасадов (распашные и ящики)
- Распашной фасад: высота = корпус - 3..4 (720 -> 716); ширина = корпус - 4 (600 -> 596, 1,5-2 с каждой стороны). Двустворчатый: (ширина - 4 - 3 межфасадный)/2 -> для 800: 396 + 3 + 396... практически 397x2.
- Навесные: 720 -> 716; 360 -> 356; 900 -> 896; 920 -> 916.
- Фасады ящиков: зазор 3 между фасадами. Для n одинаковых: h = (H_корпуса - 3*(n-1))/n  (под верхний зазор со столешницей также оставляют 2-4).
- Типовые наборы фасадов в корпусе 720 (сумма фасадов + зазоры 3 мм ~ 716):
  - 2 ящика: 356 + 356;
  - 3 ящика: 140 + 283 + 283 (или 176 + 176 + 356; 238 x 3 = 714);
  - 4 ящика: 140 + 140 + 213 + 213 (или 176 x 4 = 704 + 9);
  - 1 + дверь: 140 (ящик) + 570 (дверь) / 176 + 536;
  - под варочной: ящик 140 (или фальш-фасад) + 2 ящика 283.
- Кухонные модульные линейки фасадов (высоты): 140/176/283/356/570/716/896/916 — привязка к шагу 36/37 мм (система 32 мм + зазоры) у многих фабрик.

### 1.8 Фальшпанели и доборы
- Фальшпанель торцевая: толщина 16-18 (как фасад), по высоте = цоколь + корпус (820-870) или до пола, по глубине = корпус + фасад (576-580).
- Добор (планка) к стене при неровных стенах 20-50 (подрезается по месту); к потолку — карниз/планка 50-150 или антресоль 360.
- Стандарт "угловой зазорник" 50-100 между модулями в углу.
- Цоколь-планка по высоте 100/120/150, заглублена на 50-70.

| Параметр | Значение |

| Общая глубина | 600 (стандарт); 450-500 с евроштангами; 650-700 для верхней одежды |
| Глубина под двери (направляющие + двери) | 80-100 -> полезная ~500 при 600 |
| Ширина двери | min 500, max 1100 (Aristo); оптимум 600-900 |
| Кол-во дверей | 2 двери: шкаф 1000-1700; 3 двери: 1800-2500; 4 двери: 2500-4000 |
| Соотношение высота:ширина двери | не более 4:1 |
| Высота двери | проём - 40 (Aristo, Raumplus; у части систем -45) |
| Нахлёст дверей | 25-26 (C-профиль, асимметричная ручка); 32-35 (H-профиль, симметричная) |
| Длина направляющих | ширина проёма - 2 |
| Длина вертикального профиля | хлыст 5500 (половинка 2750) |
| Макс. высота двери | ~2750 по профилю; до 3500 с разделителями |

Формулы ширины двери (Aristo, без шлегеля; со шлегелем на 2-3 мм меньше):
- 2 двери: C: Lдв = (Lпр + 25)/2;  H: Lдв = (Lпр + 35)/2
- 3 двери: C: Lдв = (Lпр + 50)/3;  H: Lдв = (Lпр + 70)/3
- Общая: Lдв = (Lпр + k x нахлёст)/n, где k = число перекрытий (n-1 при последовательной схеме; 4 двери "попарно" - 2 перекрытия, "шахматно" - 3).
- Пример (Raumplus-подобная, нахлёст 26): проём 1600 -> (1600+26)/2 = 813.

Заполнения (Aristo):
- ЛДСП 10 мм (фрезерованная): высота = Hдв - 57; ширина = Lдв - 36 (C) / Lдв - 54 (H).
- Зеркало/стекло 4 мм: ещё -3 от ЛДСП: высота = Hдв - 60; ширина = Lдв - 39 (C) / Lдв - 57 (H). Уплотнитель (силикон/ПВХ) на кромку стекла.
- Raumplus: логика та же; при вставке 8 мм размеры минус 2 от значений для ЛДСП 10; точные вычеты — по калькулятору системы.

### 2.5 Ограничение по высоте листа
- Листы ЛДСП: 2750x1830 (Kronostar, Увадрев, Шекснинский КДП, ЧФМК); 2800x2070 (Egger, Kronospan); также 2440x1830, 2500x1830/1850, 2620x1830, 3060x1830, 3500x1750.
- Макс. неделимая боковина: ~2735-2740 при листе 2750 (минус торцовка); ~2780 при листе 2800. Выше — делить на корпус + антресоль.
- Сборка лёжа и подъём: диагональ боковины sqrt(H^2 + D^2) должна быть меньше высоты потолка (пример: 2600x600 -> диагональ 2668).

## 3. Прочие изделия

### 3.1 Тумба под ТВ
- Напольная низкая: высота 300-350 (до 400-600), глубина 400-500, ширина >= ширины ТВ (практика ТВ + 200-300 с каждой стороны).
- Узкая высокая: 600-800 x 800 x 300-400; широкая 1000 x 500 x 500.
- Высота тумбы = h глаз сидя - 2/3 h экрана - h ножек ТВ; центр экрана ~ на уровне глаз (сидя ~1000-1100 от пола).

### 3.2 Комод
- Высота: спальня ~850; стандарт 1000-1300; гостиная ~1300. Ширина 600-1200 (детская ~800). Глубина 400-500 (узкий 300-400, max 600).
- Ящик: внутр. высота 130-370; фасад 170-200 (стандарт) ... 400; глубина ящика ~450 (направляющие 350-500).

### 3.3 Прикроватная тумба
- Верх = уровень верха матраса или на 30-50 ниже; типично 450-600 (диапазон 300-600).
- Ширина 400-600 (1/3-1/2 ширины спального места на одного); глубина 350-450 (300-500).
- Зазор до матраса 50-100.

### 3.4 Письменный / компьютерный стол
| Параметр | Значение |
|---|---|
| Высота | 720-760 (стандарт 750); ГОСТ 13025.3: рабочая плоскость >= 650 |
| Столешница письменного (ГОСТ) | L >= 800, B >= 500 |
| Практика | 1200-1400 x 600-800; компьютерный min глубина 450, оптимум 600 |
| Стол - сиденье (ГОСТ) | 290-310 |
| Низ подстолья (царги) - сиденье (ГОСТ) | >= 190; от пола >= 620 (реком. 640-660) |
| Место для ног | ширина >= 500-600; глубина на уровне колен >= 450, стоп >= 600-650 |
| Посадочное место за обеденным (ГОСТ) | >= 600 x 400; кухонный >= 500 x 300 |
| Тумба выкатная (практика) | высота 550-600, глубина 450-500, ширина 400-450 |

### 3.5 Стеллажи и офисные шкафы
- Книги: глубина 250-300 (ГОСТ 140-440), шаг 250-350 (ГОСТ 180-390).
- A4-папки: глубина полки >= 300, оптимум 350; корпус 400. Регистратор ~285x320x50/75 -> светлая высота полки >= 320 (шаг ~350-370).
- Офисный шкаф: высота 1850-2000 (5 уровней папок), ширина 400/800/900, глубина 400-450; низкий 750-1150.
- Пролёт полки 16 мм <= 800; 22-25 мм <= 900-1000.

### 3.6 Кровати из ЛДСП
- Матрасы (ГОСТ 13025.2): одинарные 700/800/900 x 1860-2050; двойные 1100-1800 (шаг 100). Рыночные: 800/900/1200/1400/1600/1800 x 1900/2000.
- Ниша (внутр. размер короба) = матрас + 10..20 по ширине и длине.
- Высота ложа над полом (ГОСТ) >= 120 до основания; практика верх матраса 450-550 (пример: ламели 280 + матрас 240 = 520).
- Царги: ЛДСП 22 (или 16 в 2 слоя / с усилением), высота 200-300; основание — ламели на раме или фанера >= 10.

- Двухъярусная/чердак: от нижнего матраса до низа верхнего яруса 900-1000; бортик >= 160 над матрасом (лучше 300).
- Детский шкаф: высота 2000-2400; штанга 1200-1300 (4-8 лет), 1400-1500 (8-12 лет).

### 3.8 Прихожая
- Шкаф: глубина 400-600 (узкий коридор 350-400), высота 1800-2200 (до потолка), ширина 800-1500.
- Штанга/крючки 1700-1800; полка головных уборов глубина >= 240 (ГОСТ).
- Обувница с откидными (наклонными) секциями: глубина 250-350, наклон 10-15 град; горизонтальные полки — глубина 320 (ГОСТ), шаг 150 / 400 (сапоги).
- Банкетка: высота 400-500, ширина 600-800.

### 3.9 Ванная
- Материал: влагостойкая ЛДСП (класс эмиссии E1), кромка ПВХ 2 мм по всем торцам, опоры/подвес; зазор в цоколе на вентиляцию.
- Тумба под раковину: ширина 350-500 (компакт), 600, 800 (стандарт), 1000-1200; глубина 450-500 (компакт 350-400); высота верха раковины 850-900 от пола (индивидуально на 50-100 ниже локтя).

## 4. Эргономика

### 4.1 Зоны доступа по высоте (взрослый ~165-175 см)
| Зона | Высота от пола | Что хранить |
|---|---|---|
| Нижняя | 0-600 (до 750-850) | тяжёлое, редкое, обувь, выдвижные ящики |
| Удобная для ящиков | 600-1200 | мелочи, бельё (видно сверху, без наклона) |
| Средняя (активная) | 600/750-1800/1900 | ежедневное; рабочая зона рук 550-1050 |
| Верхняя | > 1800-1900 | лёгкое сезонное, антресоль |
- Max высота активной полки / штанги: 1900 (ГОСТ 13025.1 для штанги и верхней полки кухонного шкафа); комфортно 1700-1800.
- Выше 1900 — только пантограф, лифт-механизм или стремянка.

### 4.2 Проходы и зоны открывания
| Ситуация | Минимум | Комфортно |
|---|---|---|
| Перед распашными дверями шкафа | 700 (ширина створки + запас) | 800-900 |
| Перед выдвижными ящиками | глубина ящика + 500..600 (итого ~ 900-1000) | 1000-1200 |
| Перед шкафом-купе | 500-600 | 700-800 |
| Гардеробная, хранение с одной стороны | 600 | 800-1000 |
| Гардеробная с ящиками с двух сторон | 1000 | 1200 |
| Между рядами кухни | 1000 | 1200-1500 (двое — 1500) |
| Кровать - шкаф | 600 | 800 |
| Кровать - комод | 760 | 910 |
| Проход-коридор вдоль мебели | 500-800 | |
- Петли стандарт 110 град; для выдвижения внутренних ящиков за дверью — петли 155-170 град или отступ ящика от боковины (под толщину двери) ~20-30; в углу — зазорник 50-100, чтобы фасады/ручки не упирались.
- Распашная створка не шире 600 (при ширине > 600 ухудшается нагрузка на петли и зона открывания).

### 4.3 Место для ног
- Под столом: ширина >= 500-600, высота до низа царги >= 620 (реком. 640-660), глубина >= 450 (колени) / 600-650 (стопы).
- Под кухонным цоколем — заглубление >= 50 (ГОСТ 13025.1) под носки ног.
- Стол-сиденье 290-310; низ подстолья-сиденье >= 190 (ГОСТ 13025.3).

### 4.4 Формулы высоты от роста (R — рост)
- Кухонная рабочая поверхность: H = R/2 + 50 мм (R 1600 -> 850); альтернатива — локоть (согнутый 90 град) минус 150 (100-150).
- Таблица кухня: 1500-1600 -> 800-820; 1650-1750 -> 850-880; 1800-1900 -> 900-950.
- Письменный стол: H = R x 750/1750 ≈ R x 0,43 (0,43-0,46). R 1750 -> 750.
- Тумба под раковину: на 50-100 ниже локтя (обычно 850-900).
- Навесные кухонные шкафы: низ 1350-1600 (выше для высоких), верх <= 2200-2300 без стремянки.

## 5. ГОСТы 13025 (ключевые числа)

Внимание к нумерации: 13025.1 — отделения для хранения; 13025.2 — мебель для сидения и лежания (кровати); 13025.3 — столы.

### ГОСТ 13025.1-85 "Функциональные размеры отделений для хранения"
- Штанга: верх штанги / рабочая поверхность верхнего крючка <= 1900 от пола (выше — только с механизмом опускания).
- Головные уборы: глубина >= 240.
- Бельё: постельное 400x460 (попереч.) / 460x400; прочее 300x400 / 400x300; расстояние между полками >= 170; борт выдвижных полок >= 30.
- Постельные принадлежности: объём >= 0,11 м3; ящик в диване-кровати высота >= 120.
- Книги: между полками 180-390; глубина 140-440.
- Посуда (глубина / между полками): малая >= 150 / >= 150; средняя >= 220 / >= 200; большая >= 280 / >= 250.
- Столовые приборы: ящик L >= 260, H >= 50; столовое бельё L >= 360, B >= 260, H >= 75; верхний ящик <= 1250 от пола.
- Обувь: туфли 320x150 (гориз., глубина x высота) / 150x320 (верт.); сапоги 320x400 / 400x320; ширина на пару >= 250 (раздельно >= 125).
- Кухонные шкафы: рабочая поверхность 850-900; доп. поверхность >= 620; основание (цоколь) >= 80; глубина крышки 600; внутр. глубина напольного >= 460; заглубление основания >= 50; внутр. глубина настенного >= 270; верхняя полка <= 1900.

### ГОСТ 13025.2-85 "Мебель для сидения и лежания"
- Матрасы/ложе: одинарные ширина 700/800/900, длина 1860-2050; двойные ширина 1100-1800 (шаг 100).
- Высота ложа (до опоры матраса) >= 120 от пола.
- Глубина сиденья: стулья 360-450; рабочие кресла 400-500; кресла и диваны для отдыха 450-600.

### ГОСТ 13025.3-85 "Функциональные размеры столов"
- Высота обеденного/письменного 710-780 (распространено 750); рабочая плоскость письменного >= 650 от пола.
- Письменный стол: рабочая плоскость L >= 800, B >= 500; глубина рабочей зоны >= 400. Секретер: L >= 700, B >= 400.
- Посадочное место >= 600 x 400 (кухонный стол >= 500 x 300).
- Обеденный стол L >= 1200: расстояние между ножками по продольной оси >= 910.
- Стол - сиденье 290-310; низ подстолья - сиденье >= 190.
